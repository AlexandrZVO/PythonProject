# Учебный проект по уроку 14.1

## Создаем ветку разработки и ветку разработки текущего домашнего задания. Реализуем в ней выполнение функций :
Создаем классы Product и Category и их свойства. Добавлена инициализация. Добавлены атрибуты класса Category.
Тестируем все функции. Создаем  README-файл .
Отправляем на удаленный репозиторий и делаем pull request.

## Установка
1. Клонируйте репозитарий:
git@github.com:AlexandrZVO/PythonProject.git
2. Создайте виртуальное окружение:
poetry shell
3. Установите зависимости:
pip install -r requirements.txt
4. Установите pytest:
poetry add --group dev pytest-cov

## Использование: 
1. Откройте приложение в вашем веб-браузере. 
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.
4. src/main.py — реализация классов Product и Category. 14.1_main.py — демонстрационный скрипт: 
после подключения импорта проверяет, что код выполняется без ошибок.
